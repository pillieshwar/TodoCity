# Logos

Official logo files, named by id. TodoCity shows them wherever it shows that
agent or app: on a task's "from" chip, in Calendar, in the agent panel and in
Settings → AI → Agents.

| File | For |
|---|---|
| `claude.svg` | Claude (Claude Code, Claude Desktop): agents, and tasks they add |
| `todoist.svg` | Tasks synced or imported from Todoist |
| `things.png` | Tasks synced or imported from Things 3 |
| `codex.svg`, `antigravity.svg`, `gemini.svg`, `cursor.svg` | Those agents (not added yet) |
| `vscode.svg`, `windsurf.svg`, `lm_studio.svg` | Those apps (not added yet) |

Use the files each company publishes for partners (press or brand kits) and
follow their brand guidelines: the symbol only (no wordmark), square, on a
transparent background. Don't draw or recreate a logo.

Apps on the Mac don't need a file: a task captured from Slack, Mail, Chrome
or Outlook shows that app's own icon, read from the app by its bundle id
(`app_icons::source_icons`). A file here is for what isn't an app on the Mac,
like Todoist synced through its API, and for agents without an app (Gemini
CLI). Without either, TodoCity keeps its small glyph and the app's name.
